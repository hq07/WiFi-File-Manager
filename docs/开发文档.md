#### 功能：Windows 兼容性修复

- `server/main.py`：

## 项目架构

```
server/
├── main.py          # API 路由，文件预览/上传/下载
├── file_manager.py  # 文件操作、媒体元数据提取（ffprobe）
├── config.py        # 配置管理
└── models.py        # Pydantic 数据模型
```

│   ├── history_service.dart   # 历史记录

### 关键技术点

- **视频 SAR 修正**：服务端通过 ffprobe 提取 `sample_aspect_ratio`，计算 `display_aspect_ratio` 传给客户端，避免像素宽高比与实际显示比例不一致
- **音频后台播放**：使用 `audio_service` 插件实现通知栏控制，`just_audio` 处理音频解码，`AudioServiceActivity` 保证 FlutterEngine 一致
- **视频画面适应**：支持适配（保持宽高比）、拉伸（填满屏幕）、100%（原始尺寸）三种模式
