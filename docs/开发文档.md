## 项目架构

### 服务端（Python/FastAPI）
```
server/
├── main.py          # API 路由，文件预览/上传/下载
├── file_manager.py  # 文件操作、媒体元数据提取（ffprobe）
├── config.py        # 配置管理
└── models.py        # Pydantic 数据模型
```

### 客户端（Flutter/Dart）
```
android/lib/
├── main.dart                  # 入口，初始化服务
├── services/
│   ├── api_service.dart       # HTTP API 调用
│   ├── audio_handler.dart     # 后台音频服务
│   ├── playback_state.dart    # 播放状态管理
│   ├── history_service.dart   # 历史记录
│   ├── favorites_service.dart # 收藏
│   └── layout_prefs.dart      # 界面布局偏好
├── screens/
│   ├── login_screen.dart
│   ├── home_screen.dart
│   ├── file_list_screen.dart
│   ├── media_player_screen.dart
│   ├── file_preview_screen.dart
│   └── widgets/
│       ├── video_player_view.dart
│       ├── audio_player_view.dart
│       ├── image_gallery_view.dart
│       ├── mini_player.dart
│       └── ...
```

### 关键技术点

- **视频 SAR 修正**：服务端通过 ffprobe 提取 `sample_aspect_ratio`，计算 `display_aspect_ratio` 传给客户端，避免像素宽高比与实际显示比例不一致
- **音频后台播放**：使用 `audio_service` 插件实现通知栏控制，`just_audio` 处理音频解码，`AudioServiceActivity` 保证 FlutterEngine 一致
- **视频画面适应**：支持适配（保持宽高比）、拉伸（填满屏幕）、100%（原始尺寸）三种模式
